怎么玩

落袋,还是爆仓?
多
做多 / 看涨
觉得行情要涨就按做多，押一笔下注。
空
做空 / 看跌
觉得要跌就按做空，跌得越狠赚得越多。
平
平仓 / 落袋（主操作）
按平仓把浮盈结算成真金白银，何时收手决定你赚多少。
仓
加仓 / 满仓
押方向后再按同向键加仓（每笔=本金 1/5，最多 5 笔满仓），仓位越大盈亏越大。
秀
秀一下 / 跳跃捡钱
K线上偶尔有金币，按秀一下键跳起够到即入袋，空中翻跟头还能×连击翻倍。
!
浮盈浮亏 / 破产
押对方向赚、押反方向亏，盈亏=仓位×真实涨跌，平仓才落袋；无强平爆仓。资金从 $1,000 起步，亏到归零=破产本局结束。
