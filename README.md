# Stonk Rider for DSH Web

在左侧栏点 **Stonk Rider**。中间运行原版 **K 线狂飙 1.0.73**，右侧使用当前会话的 DSH 聊天记录和输入框。

```powershell
dsh plugin --profile web add "<dsh-stonk-rider-0.7.4.tgz 的绝对路径>"
dsh web
```

安装后重启 DSH Web。按原版 **出发** 随机抽取 56 个标的之一。首页会显示当前赛程的回合、本金、峰值和已带卡数：金币捡到后立刻计入本局资金，真正跨回合滚存的是冲线后的赛程本金，破产或半场退赛会清空。骑行时 `↑` 做多、`↓` 做空、`空格` / `←` / `X` 平仓，`→` 秀一下（跳跃和空翻）。没有方向键的键盘（部分 Mac）可用 `W` 做多、`S` 做空、`D` 秀一下、`空格` / `X` 平仓。游戏画面内的触控按钮上会直接标出对应快捷键（如 `↑ W`、`空格 X`），macOS 上空格显示为 `Space`。同向加仓，反向平仓后开新仓。冲线进入休整室，可以三选一或跳过，资金和卡组会带进下一回合。原版分享卡、行情库、音乐和本地赛程存档都可使用。B 站 Toy 排行榜属于原平台能力，DSH 版使用本地记录。

- 冲线后，在原版休整室的 **关键时刻回顾** 点「问 DSH」，可复盘当时的仓位。展开 **本回合交易** 可以逐笔查看开仓、加仓、反手和平仓，问题会附上当笔的基础盈亏、实际结算和触发的调整。右侧读完后，点 **去选卡** 回到原版升级选择。窄窗口先点顶部 **返回休整室**。
- 点赛道下方的 **关键价格节点**，会把当前标的的相邻历史采样价带入对话。点 **问当前赛段**，会带上当前持仓和已结算盈亏。到休整室或结算页也可以点 **复盘本回合** 获取整局概览。
- 提问时暂停骑行。问题追加到已有草稿，附件保留，确认后由你发送。窄窗口用顶部按钮在赛道和对话之间切换。联动在 DSH Web `0.2.2-rc.1` 上验证。

卸载使用 `dsh plugin --profile web remove dsh-stonk-rider`。

## 源码

- `src/original/` 包含原版源码和资源，来自用户提供的 Git bundle，提交 `23ce2d266eff84ee478c1e28279e7bb9d8eb5667`。构建时接入本地数据、隔离运行、暂停和本回合交易复盘。逐笔流水用于当前休整室。旧版合集补丁对应早期原型。
- 游戏之外使用 shadcn/ui New York v4，组件与 MIT 许可在 `src/ui`。重新构建可运行 `npm ci`、`npm run build`、`npm pack`。
